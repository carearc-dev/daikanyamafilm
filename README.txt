DAIKANYAMA FILM — GitHub Pages公開データ

このフォルダの中身をGitHubリポジトリの公開ルートへアップロードしてください。

トップ階層にあるファイル：
- index.html — ページ本体
- style.css — デザイン用CSS（独立ファイル）
- script.js — ページ表示用JavaScript
- img/ — 写真・ロゴなどの画像
- 404.html — /works などへの直接アクセス用
- .nojekyll — GitHub Pages設定用

このままユーザー/組織ページ、独自ドメイン、リポジトリ配下のGitHub Pagesで使える相対パスに設定済みです。
source/には編集用のReact/CSSソースを入れています。公開にはトップ階層のファイルを使います。
